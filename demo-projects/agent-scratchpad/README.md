# agent scratchpad

A tiny loop that picks a tool, maybe writes JSON memory, and sometimes posts to Slack. I am copying the shape of those architecture diagrams, not building an operating system.

It reads prompts from `prompt-vault` when I remember to paste one, and it searches the meeting notes the same way meeting-notes-rag does. Copilot generated the first router. `decisions.md` says what I kept.

This mentions inbox-triage only as a wish: someday the agent could label mail. It does not.
